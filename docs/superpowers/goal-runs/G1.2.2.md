# Goal run — G1.2.2

**Goal ID:** `G1.2.2`
**Status:** `done`

## Decision

**Playwright is the single E2E server owner.** `apps/pwa/e2e/playwright.config.ts` owns fixture API, standalone Next server, and service-worker harness through `webServer`. `apps/pwa/e2e/run-ci.sh` only selects Playwright projects and runs the matrix gate; it no longer starts, waits for, kills, or cleans up servers.

## Implementation

- Playwright webServer builds with `build:next:cloudflare` and starts `.next/standalone/server.js`.
- The runner executes functional mobile, PWA runtime, and functional desktop projects in one Playwright invocation, then runs the matrix contract.
- The old duplicate PID lifecycle (`FIXTURE_PID`, `NEXT_PID`, `SW_PID`) was removed.
- `e2e-owner.test.ts` locks the ownership contract.

## Verification

- Ownership contract: 1/1 passed.
- Full local Playwright run: 250 passed, including functional mobile, functional desktop, PWA runtime, production opt-in guard, and matrix coverage; no server ownership or startup collision occurred.
- Failure guard now recognizes only browser-aborted RSC/font requests as expected transport cancellations, covered by unit tests.
