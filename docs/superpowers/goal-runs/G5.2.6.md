# Goal run — G5.2.6

**Goal ID:** G5.2.6
**Status:** ready for auditor

## Contract

- **Objective:** Aplicar matriz configurável: operações com valor `>= R$500` exigem aprovação; operações destrutivas sempre exigem aprovação; somente o requestor pode aprovar/rejeitar.
- **Boundary:** API é o único boundary de side effect. Agent emite token delegado; Pi chama HTTP. Nenhum desses runtimes executa SQL financeiro diretamente.
- **Persistence:** `PendingOperation` é criado antes do side effect. Postgres usa store durável; testes usam store em memória. Aprovação apenas muda o estado; execução atômica do payload é G5.2.7.
