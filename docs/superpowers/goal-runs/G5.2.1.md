# G5.2.1 — Tools geradas de contratos HTTP

## Entrega

- Contrato OpenAPI canônico: `apps/api/openapi/agent-tools.openapi.json`, cobrindo todas as 44 capabilities API migradas como operações de path OpenAPI, incluindo a variante necessária no path compartilhado.
- Gerador determinístico: `scripts/generate-agent-tools.mjs`.
- Artefato gerado: `.pi/extensions/financial-tools/generated/http-tools.ts` com 44 tools e schemas TypeBox derivados de parâmetros, enums, formatos, limites e arrays.
- O cliente gerado trata headers genericamente e a comparação de schemas cobre requiredness, tipos e posicionamento.
- Todas as facades das 44 capabilities API apenas reexportam o artefato gerado; implementações não-HTTP permaneceram separadas.
- Projeções de resposta e shadow read são declaradas no contrato (`x-pi-tool`) e emitidas pelo gerador.
- `agent-tools:generate` e `agent-tools:check` foram adicionados ao root package.

## Evidência

- `node --test scripts/generate-agent-tools.test.mjs scripts/agent-tools-schema-contract.test.mjs scripts/agent-tools-authoritative-query.test.mjs`: 27/27, incluindo comparação exata com `migratedApiCapabilities`, verificação dos 44 métodos/paths/posicionamentos, filtros de query autoritativos e validação contra schemas Zod da API.
- As 37 listas `x-pi-tool.parameters` foram eliminadas; parâmetros agora vêm exclusivamente de `operation.parameters` e `requestBody`. `audit_logs.entityType` preserva `minLength: 1`.
- `apps/api/tests/contract/agent-tools-authoritative-all.test.ts` cobre os 44 tools: cada input é comparado diretamente contra schemas Zod exportados da API, incluindo requiredness, enums, tipos, limites e regex, ou explicitamente marcado como rota sem input.
- `create_account`/`create_category` não expõem mais `force`, que não existe nos schemas HTTP autoritativos.
- `GET /accounts/:id` foi adicionado como endpoint tipado para `get_balance`; teste de integração cobre retorno da conta, isolamento por household e URL gerada.
- O contrato foi corrigido para `list_statements`, `update_account`, defaults de audit logs, filtros de transações, enums de contas/categorias e `create_expense.amountCents` positivo.
- O gerador valida cada uma das 44 rotas contra `apps/api/src/routes/route-inventory.ts`, evitando operações OpenAPI para endpoints inexistentes.
- O gerador também trata headers genericamente e preserva constraints de arrays, enums, formatos, defaults e limites.
- `pnpm agent-tools:check`: artefato atualizado, 44 tools.
- `pnpm test:agent-tools`: suíte agregada passou.
- `pnpm --dir .pi/extensions/financial-tools typecheck`: passou.
