# Goal run — G1.1.6

**Goal ID:** `G1.1.6`
**Status:** `done`

## Contract

- **Objective:** executar o build OpenNext em Linux/CI; Windows não é baseline oficial.
- **Acceptance:** workflow CI explícito em `ubuntu-latest`, com pins Volta e `build:cloudflare`.

## Implementation

- `.github/workflows/pwa-ci.yml` mantém a qualidade PWA em Linux e adiciona o job `opennext` dedicado.
- O job usa `volta-cli/action@v4`, `pnpm install --frozen-lockfile` e `pnpm --dir apps/pwa build:cloudflare`.
- Nenhum job OpenNext usa `windows-latest`.
- `apps/pwa/build:cloudflare` continua sendo `next build --webpack` seguido de `opennextjs-cloudflare build --skipBuild`.

## Evidence

- `apps/pwa/src/__tests__/pwa-ci-workflow.test.ts`: workflow audit passou com a asserção Linux/OpenNext.
- `pnpm --filter pwa build`: Windows Next/Webpack build passou; OpenNext é validado no job Linux por incompatibilidade conhecida de filesystem Windows.
- `pnpm lint`, `pnpm typecheck` e `pnpm test`: passaram antes da conclusão.
