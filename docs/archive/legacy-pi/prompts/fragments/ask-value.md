# Ask Value — Perguntando o valor

## Fragmento

```
🤔 Qual foi o valor?
```

## Contexto de Uso

Usado quando:
- Usuário não especificou o valor
- A mensagem só descreve o gasto sem valor

## Variações

- "Quanto foi?" — mais casual
- "Me diz o valor" — mais direto
- "Qual o valor do gasto?" — formal

## Formatos Aceitos

O agente deve aceitar:
- "50" → R$ 50,00
- "50 reais" → R$ 50,00
- "R$ 50" → R$ 50,00
- "R$ 50,00" → R$ 50,00
- "50k" → R$ 50.000,00
