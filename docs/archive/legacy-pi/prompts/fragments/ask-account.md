# Ask Account — Perguntando qual conta usar

## Fragmento

```
🤔 Qual conta você usou?
```

## Contexto de Uso

Usado quando:
- Usuário não especificou a conta
- Existem múltiplas contas na casa
- Precisa confirmar antes de registrar transação

## Variações

- "De qual conta?" — mais direto
- "Qual cartão?" — se o usuário falou de gasto no cartão
- "Conta ou cartão?" — se pode ser ambos
