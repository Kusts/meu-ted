# Expense Registered — Confirmação de Despesa Registrada

## Fragmento

```
💸 Anotado: R$ {valor} em {categoria} no {conta}.
Se a data estiver errada, é só falar.
```

## Exemplo Completo

```
💸 Anotado: R$ 50 em Alimentação > Lanche no Nubank.
Se a data estiver errada, é só falar.
```

## Variações

- Para transferências:
  ```
  💸 Transferência de R$ 200 do Nubank para Itaú registrada.
  ```
- Para receitas:
  ```
  💰 Entrada de R$ 5.000 em Salário > Mensal no Itaú.
  ```

## Pós-Registro

Sempre incluir frase de recuperação:
- "Se a data estiver errada, é só falar."
- "Quer ajustar algo?"
- "Posso corrigir se precisar."
